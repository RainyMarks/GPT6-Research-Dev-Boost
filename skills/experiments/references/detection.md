# 检测类任务（AIGC 生成内容、深度伪造）

- 除了同分布测试，还要报告跨生成器、跨数据集的泛化：在一部分生成器或数据集上训练，在没见过的上面测试。
- 报告对常见扰动的鲁棒性：JPEG 压缩、缩放、裁剪、模糊、加噪，以及经过社交平台转发后的版本。
- 真实样本和生成样本的格式、分辨率、压缩质量和来源要对齐，否则检测器可能只学会区分格式。
- 深度伪造按人物身份或视频划分；除非实验设定明确如此，同一个人的不同视频也不跨越训练和测试。
- 指标同时给 AUC 和固定阈值下的准确率或 EER，阈值在验证集上确定。语音伪造报告 EER 和 min t-DCF，按说话人划分。
- 数据有没有格式、分辨率、静音时长之类的捷径，用 `data-gathering` 的 `scripts/check_dataset.py` 检查。

## 可信取证

取证结论要拿去支撑判断，除了准确率还要回答：

- 置信度可信吗：报告校准误差（ECE）和可靠性图；支持拒判的，报告不同覆盖率下的错误率。
- 能扛住针对性攻击吗：假设攻击者知道检测器，做白盒和黑盒的规避攻击，报告攻击下的检出率和所需的扰动大小（Carlini and Farid, CVPRW 2020, doi:10.1109/CVPRW50498.2020.00337 把一个 AUC 0.95 的合成图像检测器攻击到准确率接近 0%）。反取证处理（重压缩、重采样、去伪影滤波）单独报告。
- 能指出篡改在哪吗：局部篡改报告像素级 F1、IoU 或 AUC，按篡改面积分档。
- 解释站得住吗：声称热力图或证据区域反映判断依据时，做删除测试（遮掉高亮区域后预测是否改变），把它和随机区域对比。
