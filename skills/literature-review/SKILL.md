# 文献调研

## 检索

- 用多个来源：arXiv、Semantic Scholar、Google Scholar、DBLP、OpenReview 和会议官网。关键词连同同义词、上位词都试一遍，再顺着关键论文的参考文献和被引列表往下找。
- 同时覆盖最近两三年的工作和奠基性工作。写“最新”“目前最好”时注明检索日期。
- 网站打不开时跳过，并在汇报里说明，不为此修改任何网络配置。

## 核对

- 每篇都打开看过再写：至少读摘要、方法和主要结果，核对标题、作者、年份和发表处。
- 区分预印本和已发表论文；预印本已经正式发表的，用正式版本。
- 引用数和会议级别只作参考，不替代对内容的判断。
- 需要 BibTeX 时，用 `paper-writing` skill 目录下的 `scripts/fetch_bibtex.py`。

## 输出

- 来源清单：标题、作者、年份、发表处，以及 DOI、arXiv ID 或链接。逐条写明是在哪个页面核对的。“核对过”指这次实际打开或检索到了该文献的页面；凭记忆写的不算，标注“未核实”。每条结论都能对应到来源。
- 相关工作按方法类别或问题设定组织，说清每一类的思路、代表工作和局限，不逐篇罗列摘要。
- 指出研究空白和可以做的方向。

## 新颖性核查

把用户的想法和最接近的已有工作逐项对比（问题设定、方法、数据、结论），给出“已有人做过”“部分重叠”或“没有找到”的判断，并写明检索范围和关键词。同时写出差异化的切入点：怎样改问题设定、方法或评测，才能和这些工作拉开距离。
